# Order Management System

## Overview

The Order Management System is designed to streamline the order processing workflow for various applications including Kitchen Display, Checkout, and Backend APIs. This system aims to provide a seamless user experience while managing orders efficiently. 

### Features
- **Backend API**: Comprehensive API to handle order management tasks linked with the database and front-end interfaces.
- **Kitchen Display**: A user-friendly Angular application designed for kitchen staff to view and manage current orders.
- **Checkout System**: An Angular application to facilitate the customer checkout process and order finalization.

### Technologies Used
- .NET 10 for Backend API
- Angular for Frontend Applications

### Getting Started
To set up the project locally, follow these steps:
1. Clone the repository.
2. Navigate to the backend directory and restore the .NET packages.
3. Set up the Angular applications as specified in their respective README files.
